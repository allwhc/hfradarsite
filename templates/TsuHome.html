AboutBenefits
It is a web-based Monthly report monitoring system that allows authorized users to display and manage all monthly and yearly data of all remote sites of ICORN.
The system consists of a Online Server for storing data count, an Automated script at each remote site computer and a Mobile application provided to the site Technician.
At set period Automated script at the remote computer gets activated and counts radial data which is above 20Kb (optional feature) in size for quality assurance (QA) accurately and sends it to the server via the internet.
The existing server can handle up to 10 sites; it is expandable up to 20 more sites. The following is the explanation of each part of the system.
User-friendly web-based interface to easily display and manage historical and real-time data.
It receives data from all remote sites periodically from automated scripts or Android mobile phones and displays data in the desired format required for monthly reports.
It stores data from past years which can be accessed anytime and anywhere.
Server stores only the data count of files and not actual data for Security purposes.
The received data count is represented in Monthly and Yearly format.
Access to the web server and its functionalities is completely password protected.
1) Reduce human error for file counting.
2) Accurate Quality Assurance flag ( for eliminating file count for file size less than 20kB optional features)
3) On time Report generation and maintain history of data generated
4) Report updates even when site Internet down and during absence of site technician
5) True totals report is useful to verify data available at Central Server.
